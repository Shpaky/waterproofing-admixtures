# Второй акцент и бетонная фактура

Дата: 2026-09-11. Две точечные правки визуального языка без изменения контента,
структуры секций и вёрстки.

## Зачем второй акцент

Синий — цвет всей отрасли строительной химии (Köster, Kryton, Xypex, Master Builders,
GCP, Dr. Fixit). Наш `#0938BD` корректен, но не отличает сайт ни от кого. Введён тёплый
сигнальный акцент в диапазоне охры и оранжевой строительной разметки. Он в родстве
с тёплым серым бетона (оба уведены от голубого в тёплую сторону) и читается как
«технический слой», а не как второй бренд.

## Роли

| Цвет | Роль | Где |
|---|---|---|
| `brand-*` (синий) | бренд, действие | логотип, основная CTA, ссылки, активная навигация, иконки преимуществ |
| `signal-*` (тёплый) | технический слой | числа и единицы в «Ключевых данных», номера шагов и плашки проблем в «Как работает», выноска результата, колонка D5 в таблице сравнения, кристаллы на схеме, шевроны FAQ, предупреждение о предварительных данных |

Правила:

- Сигнальный цвет занимает не более 10 % окрашенной площади экрана.
- Две равновесные кнопки разных цветов рядом запрещены; сигнальный цвет не бывает
  цветом кнопки.
- Ни один смысл не передаётся только цветом: у каждого маркера есть текст, иконка или
  подпись (номера шагов, «Да/Нет» с иконками, звёздочка с расшифровкой).
- `signal-500` не несёт текста: белый на нём даёт 3.6:1. Текст на светлом фоне только
  `signal-600`, на тёмных полосах только `signal-400`.

## Токены

| Токен | Значение | Применение |
|---|---|---|
| `signal-100` | `#F6E4DA` | фон выноски, плашек проблем, колонки D5 |
| `signal-400` | `#E08A5C` | текст и иконки сигнального слоя на `brand-950`, `brand-900`, `surface-concrete-dark` |
| `signal-500` | `#D2691E` | рамки, подчёркивания, обводка номеров шагов; без текста |
| `signal-600` | `#A64A12` | текст и иконки сигнального слоя на светлом фоне |
| `signal-900` | `#3A2417` | резерв под тёмную тему для фона плашек |
| `surface-concrete` | `#E9E7E3` | светлая бетонная полоса |
| `surface-concrete-dark` | `#171A1D` | тёмная бетонная полоса (футер) |

Исходное `#B4541C` для текста отклонено: на бетоне даёт 4.02:1. Принято `#A64A12`.

## Фактура

Инлайновый SVG с `feTurbulence` в data URI, только `background-image`, два варианта:
`texture-concrete` (тёмное зерно ~4 % на светлом бетоне) и `texture-concrete-dark`
(светлое зерно ~5 % на тёмных полосах). Вес каждого около 0,6 КБ, растров и зависимостей
нет, макет не сдвигается.

Ритм полос сверху вниз:

| Полоса | Фон |
|---|---|
| Hero | brand-950 + фактура |
| Как работает | чистый белый |
| Продукты | чистый surface-alt |
| Преимущества и сравнение | бетон `#E9E7E3` + фактура |
| Применение | чистый surface-dark |
| Для кого | чистый белый |
| Документы | чистый surface-alt |
| FAQ | чистый белый |
| Футер | бетон `#171A1D` + фактура |

Фактуры не должно быть на карточках, кнопках, таблицах и в шапке: она только на
фоне полос, карточки поверх неё остаются чистыми.

## Тёмная тема

В проекте нет тёмной темы: ни `data-theme`, ни переопределений под
`prefers-color-scheme`, а базовая палитра определена только для светлого вида.
Переопределять сигнальные цвета внутри медиазапроса при светлой странице нельзя,
это сломает контраст у пользователей с тёмной ОС. Поэтому «тёмные» значения введены
как самостоятельные токены (`signal-400`, `signal-900`, `surface-concrete-dark`) и
применены на тёмных полосах страницы. Для полноценной тёмной темы потребуются ролевые
токены всей палитры, это отдельная задача.
